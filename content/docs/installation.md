# Installation

## Package Manager
1. Open Package Manager 
  > In **Unity Editor** go to **Window > Package Management** and select **Package Manager**
2. Inside **Package Manger** click on a plus sign and select ```install package from gitUrl```
3. Paste ```https://github.com/BluePixelDev/audipool``` and install

## Open UPM

### Scoped Registry
1. Go to **Project > Project Settings**
2. In the newly opened window select **Package Manager**
3. Add new scoped registry
> Set **URL** as ``https://package.openupm.com`` and into the **Scope(s)** field add ``com.bluepixel.audipool``

## Manual
As a last option, you may also just download the source code and import it into your **Unity Project**.
